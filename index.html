FREE VILLAGE

Jamaica, 1838 — Freedom Is Only the Beginning

You are a newly emancipated Jamaican building a life beyond the plantation. Buy or work land, grow provisions, trade in the village, form community, learn your rights, and help establish a free village.

This is a small playable prototype. It uses original pixel-art-style shapes rather than external assets, so it can run as a single file on GitHub Pages.
